# Changelog

All notable changes to AIMS-mini are documented here.

## [Unreleased]

### Added
- `search_by_category()` and cart sorting helpers.

## [1.1.0] - 2026-11-05

### Added
- Add search by category.
- Add sorting features for cart.

### Fixed
- Case-insensitive title search, including the `lion` / `The Lion King` case.

## [1.0.1] - 2026-11-05

### Fixed
- Make `search_by_title()` case-insensitive.

## [1.0.0] - 2026-11-05

### Added
- AIMS-mini package with DVD and cart models.
- Cart display, discount calculation and title search.
- Unit tests and command-line demonstration.

## [0.3.0]

### Added
- Bugfix workflow, regression tests and conflict-resolution exercises.

## [0.2.0]

### Added
- Feature/topic workflow, pull request template and search feature.

## [0.1.0]

### Added
- Initial repository, ignore rules and refactor into the `aims` package.
